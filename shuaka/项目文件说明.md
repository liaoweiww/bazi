## 一、核心 Python 文件

### `main.py`
**用途：** 系统主程序入口。负责加载配置、初始化各模块、启动 Web 服务器。

**关键流程：**
1. 解析命令行参数（`--config`, `--no-ngrok`）
2. 加载 `config.yaml` + `settings.json`
3. 初始化 Excel 管理器、语音播报、计时提醒
4. 启动读卡器监听（Windows 多模式自动适配）
5. 启动 Flask Web 服务器
6. 启动 ngrok 外网隧道（可选）
7. 启动自动备份线程

---

### `web_server.py`
**用途：** Flask Web 服务器，提供 REST API 和前端页面。

**包含功能：**
- 叫号大屏页面服务（`/`）
- 后台管理 API + 页面（`/admin`）
- 用户登录/权限验证
- 设置读写（`/api/settings`）
- 数据管理（备份/恢复/回收站）
- Excel 数据导出
- 签名监控 API（`/api/monitor`）
- 多机事件联动（`events/` 目录轮询）
- 局域网 / 远程代码同步（`/api/sync_lan`, `/api/sync_remote`）
- 软件激活/授权管理
- 目录浏览 API（`/api/browse-dirs`）
- 数据路径验证（`/api/validate-data-path`）
- 服务重启 API（`/api/restart`）

---

### `desktop_app.py`
**用途：** Windows 桌面 GUI 控制面板（基于 customtkinter）。

**功能：**
- 显示服务状态、读卡器状态、签到统计
- 局域网同步、远程升级按钮
- 实时日志窗口
- 代码自动从 SMB 共享更新
- 打包成 `qiandao.exe`（PyInstaller）

---

### `excel_manager.py`
**用途：** Excel 签到记录管理。按地点分文件存储，支持多机并发写入。

**核心功能：**
- 读取/写入签到 Excel 文件
- 自动缓存，定时刷新
- 地点分文件存储（`签到记录_{地点}.xlsx`）

---

### `voice_broadcast.py`
**用途：** 语音播报引擎。macOS 用 `say` 命令，Windows 用 `pyttsx3`。

---

### `timer_manager.py`
**用途：** 签到计时提醒。监控等待时间，超时触发语音提醒 + 叫号。

---

### `card_listener.py` / `win_card_listener.py`
**用途：** 读卡器监听。macOS 用 pynput，Windows 用 Win32 API 键盘钩子。

---

### `platform_utils.py`
**用途：** 跨平台工具函数。路径检测（百度网盘/坚果云）、系统识别、硬件信息。

---

### `local_mirror.py`
**用途：** 本地数据安全镜像。将 BaiduSyncdisk 关键数据实时镜像到 `local_backup/`，防止云同步误删。

---

### `auth_manager.py`
**用途：** 软件激活/授权管理。机器码生成、license 验证。

---

### `activate_tool.py`
**用途：** 激活工具，用于生成授权码。

---

### `gen_license.py`
**用途：** 授权码生成脚本。

## 三、配置文件

### `config.yaml`
系统基础配置：地点名称、Excel 路径、读卡器模式、语音模板、计时参数、Web 端口、ngrok、自动备份。

### `settings.json`
运行时动态配置（同步于 BaiduSyncdisk），通过后台管理页面修改：主题、显示选项、语音设置、跑马灯、授权信息等。

### `users.json`
用户账户（同步于 BaiduSyncdisk），存储登录用户名/密码/角色。

### `CardInfo.ini`
读卡器参数配置。

### `requirements.txt`
Python 依赖：`flask`, `openpyxl`, `pyyaml`, `customtkinter`, `pynput`, `pyttsx3` 等。

## 八、数据流动路径

```
用户刷卡 → card_listener → main.on_signin()
    → ExcelManager.add_record() → BaiduSyncdisk/签到记录/*.xlsx
    → VoiceBroadcaster.welcome() → 语音播报
    → TimerManager.add_timer() → 超时提醒
    → 写入 events/ → 其他机器感知

云同步：
  Mac:   BaiduSyncdisk/ ←→ 坚果云 ←→ 百度网盘
  Win:   BaiduSyncdisk/ ←→ 百度网盘 ←→ 坚果云

Web 前端轮询：
  大屏:   /api/records → 签到列表
  后台:   /api/monitor → 状态面板
  语音:   /api/pending-voice → 多机联动语音
```
