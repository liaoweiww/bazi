# 身份证签到叫号系统 — 部署说明

## 系统简介  reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v EnableLinkedConnections /t REG_DWORD /d 1 /fƒ

一套**纯本地运行**的身份证签到 + 语音叫号系统。

- 后台静默监听 USB 读卡器，**不抢占硬件、不影响原有系统**
- 自动生成 Excel 签到记录，**百度网盘异地自动同步**
- 离线语音播报签到欢迎语 + **40 分钟自动提醒**
- 安卓平板 **实时叫号大屏**（医院排队叫号风格）
- 电脑浏览器 **后台管理面板**：上传 Logo、切换主题、改模板
- **支持内网 + 外网双访问**（外网需 ngrok）

**不需要 API 接口、不需要云服务器、不需要公安联网。**

---

## 一、环境准备

| 你需要什么 | 具体要求 |
|-----------|---------|
| 电脑 | Windows 10/11 或 macOS 12+ |
| Python | 3.7 以上（[python.org](https://python.org) 下载安装） |
| USB 读卡器 | HID 键盘模拟模式（市面上绝大多数读卡器默认就是） |
| 安卓平板 | Android 8.0+，有浏览器即可 |
| 百度网盘 | 电脑端安装登录，设好同步目录 |
| ngrok（可选） | 平板需要在外网访问时才需要，免费注册 [ngrok.com](https://ngrok.com) |

## 二、部署步骤（5 步搞定）

### 第 1 步：安装 Python 依赖

打开终端（Mac）或命令提示符（Win），进入 `shuaka` 目录，执行：

```bash
pip install -r requirements.txt
```

一共 5 个小包，30 秒装完：
- `pynput` — 监听读卡器键盘输入
- `openpyxl` — 读写 Excel 文件
- `flask` — 提供平板大屏网页 + 管理后台
- `pyyaml` — 读取配置文件
- `pyttsx3` — Windows 语音播报（Mac 用系统自带 `say` 命令，无需此包）

### 第 2 步：修改配置文件

用记事本打开 `config.yaml`，**只需改 2 个地方**，其余保持默认即可：

```yaml
# 1️⃣ 地点名称（两个地点必须不同！如 "北京办公室" / "上海办公室"）
location: "北京办公室"

# 2️⃣ Excel 存到哪里（改成你的百度网盘同步目录）
#    Mac 举例：/Users/张三/BaiduSyncDisk/签到记录
#    Win 举例：C:\Users\张三\BaiduSyncDisk\签到记录
excel_dir: "C:/Users/张三/BaiduSyncDisk/签到记录"
```

**完整配置项解释（新手保持默认即可）：**

```yaml
# ---- 读卡器（无需改动） ----
card_reader:
  rapid_threshold: 0.03    # 读卡器击键速度阈值，不用改
  pause_threshold: 0.8     # 刷卡结束停顿时间，不用改
  debug: false             # 调不出数据时改成 true，看原始输出

# ---- 语音播报 ----
voice:
  enabled: true            # false = 静音
  welcome_template: "{name}，欢迎签到！"
  remind_template: "{name}，您的等待已到40分钟，请留意叫号。"
  macos_voice: "Tingting"  # Mac 中文语音，终端执行 say -v '?' 看可选列表
  windows_voice: ""        # Windows 留空 = 系统默认中文语音

# ---- 计时提醒 ----
timer:
  remind_minutes: 40       # 签到后多少分钟提醒

# ---- Web 服务 ----
web_server:
  host: "0.0.0.0"          # 不用改
  port: 5002               # 端口号，冲突了换一个

# ---- 外网访问（可选） ----
ngrok:
  enabled: false           # 需要外网访问时改成 true
  auth_token: ""           # 填你在 ngrok.com 拿到的 token
```

### 第 3 步：启动程序

**Windows**：双击 `start.bat`

**macOS**：终端执行
```bash
cd shuaka
./start.sh
```

**通用方式**：
```bash
python main.py

# 如果不需要外网访问，加参数跳过 ngrok：
python main.py --no-ngrok
```

启动成功后，终端会打印：

```
=======================================================
  叫号大屏 Web 服务器已启动
  管理后台: http://192.168.1.100:5002/admin
  大屏展示: http://192.168.1.100:5002/
  ─────────────────────────────────────────────
  内网访问地址:
    http://192.168.1.100:5002
=======================================================
系统运行中... 按 Ctrl+C 退出
```

> ⚠️ **macOS 用户**：首次启动会弹窗要求"辅助功能"权限。去 **系统设置 → 隐私与安全性 → 辅助功能**，勾上你的终端应用，然后重新启动程序。

### 第 4 步：平板上打开叫号大屏

1. 确保平板和电脑连**同一个 WiFi**
2. 打开平板浏览器（Chrome 最佳）
3. 输入终端上显示的地址，如 `http://192.168.1.100:5002`
4. 点击页面右下角 **⛶ 按钮** → 全屏显示
5. **建议**：Chrome 菜单 → 添加到主屏幕 → 以后一键打开，像 App 一样

叫号大屏效果：
- 暗色主题，大字体，一目了然
- 新签到高亮动画显示
- 等待时长实时更新
- 🟢 绿色 = 正常等待 | 🟡 黄色闪烁 = 即将超时 | 🔴 红色闪烁 = 已超时
- 姓名自动脱敏（张**）
- 每 5 秒自动刷新

### 第 5 步：配置后台管理（个性化设置）

在**电脑浏览器**（不是平板）打开 `http://localhost:5002/admin`

后台管理有 5 个 Tab：

| Tab | 能做什么 |
|-----|---------|
| **大屏显示** | 改标题、上传企业 Logo、调字体大小、开关姓名脱敏、开关各列显隐 |
| **主题模板** | 一键切换 5 套主题（暗夜黑/深海蓝/商务绿/科技紫/简约白），还可以自定颜色 |
| **语音设置** | 开关语音、自定义欢迎语和提醒语模板 |
| **计时提醒** | 改提醒分钟数、改预警分钟数 |
| **数据管理** | 看今日签到数、总记录数、外网状态 |

改完后点底部 **"保存设置"** 按钮（或按 `Ctrl+S`），平板大屏约 30 秒内自动应用新设置。

### 第 6 步（可选）：外网访问

当平板和电脑不在同一 WiFi 时（比如平板用 4G/5G），需要 ngrok 内网穿透：

**1. 注册 ngrok**（免费，1 分钟）
- 打开 [ngrok.com](https://ngrok.com)，用 GitHub/Google 账号注册
- 进入 [控制台](https://dashboard.ngrok.com/get-started/your-authtoken)，复制你的 authtoken

**2. 安装 ngrok**
- Mac: `brew install ngrok`
- Win: 去 [ngrok.com/download](https://ngrok.com/download) 下载 exe，放到 `shuaka/` 目录下

**3. 改配置**
```yaml
ngrok:
  enabled: true
  auth_token: "你的authtoken"
```

**4. 重启程序**，终端会额外打印一行：
```
外网访问地址: https://xxxx.ngrok-free.app
```

平板用这个外网地址就能在任何地方访问叫号大屏了。

> 免费版 ngrok 有流量限制，但签到数据流量极小，完全够用。

## 三、异地双地点部署

两个办公室各自部署一套，百度网盘自动同步数据：

```
地点A（北京）                         地点B（上海）
┌─────────────┐                    ┌─────────────┐
│ 电脑A       │                    │ 电脑B       │
│ location:   │   百度网盘自动同步   │ location:   │
│ "北京办公室" │ ←─────────────── → │ "上海办公室" │
│             │                    │             │
│ Excel文件：  │                    │ Excel文件：  │
│ 签到记录_    │                    │ 签到记录_    │
│ 北京办公室.xlsx                   │ 上海办公室.xlsx
└─────────────┘                    └─────────────┘
     ↓                                   ↓
  平板A                               平板B
  (显示两地数据)                       (显示两地数据)
```

**关键点：**
- 两台电脑的 `location` 必须不同
- 两台电脑的 `excel_dir` 都指向各自的百度网盘同步目录
- 每台电脑写自己的文件，百度网盘帮你同步另一台的文件
- 每个地点的平板都能看到两个地点的**全部签到数据**
- **不会冲突**：文件名不同（按地点名区分）

## 四、日常操作

### 刷卡签到全自动

1. 来人在**任何窗口**刷卡（读卡器自动向当前焦点窗口输入数据）
2. 系统后台静默捕获 → 写入 Excel → 语音播报 → 启动 40 分钟倒计时
3. 40 分钟后自动语音提醒："张三，您的等待已到40分钟，请留意叫号。"
4. 平板大屏实时更新，新签到行高亮动画

**整个过程无需人工干预。**

### 手动签到（无读卡器时备用）

```bash
python manual_signin.py
```

输入姓名和身份证号即可手动录入。

### 查看签到记录

打开百度网盘同步目录里的 Excel 文件：
- `签到记录_北京办公室.xlsx`
- `签到记录_上海办公室.xlsx`

表头：序号 | 姓名 | 身份证号 | 签到时间 | 签到地点 | 状态

### Windows 开机自启动（可选）

1. 右键 `start.bat` → 创建快捷方式
2. `Win+R` → `shell:startup` → 回车
3. 把快捷方式拖进去
4. 开机自动启动签到系统

## 五、常见问题

### Q: 刷卡没反应？

1. 先在别的软件中刷一下，确认读卡器正常工作
2. 在 `config.yaml` 中设 `card_reader.debug: true`，重启程序
3. 刷卡时看终端有没有打印 `[CardReader DEBUG]` 的原始数据
4. 完全没输出 → macOS 检查辅助功能权限（第 3 步的提示）
5. 有原始数据但没解析出姓名 → 说明读卡器格式特殊，截图发我适配

### Q: 平板打不开大屏？

1. 确认平板和电脑连的同一个 WiFi
2. 电脑防火墙可能拦了 5002 端口：
   - Win：控制面板 → 防火墙 → 允许应用通过防火墙 → 允许 Python
   - Mac：系统设置 → 网络 → 防火墙 → 关闭或添加 Python 例外
3. 在电脑浏览器打开 `http://127.0.0.1:5002` 确认服务正常

### Q: 语音不播报？

- **Mac**：终端执行 `say "测试"` 看有没有声音，确认没静音
- **Win**：确认 `pyttsx3` 已装 (`pip install pyttsx3`)
- 不需要语音就设 `voice.enabled: false`

### Q: 数据会重复吗？

不会。每个地点写入**独立的 Excel 文件**（按地点名区分），百度网盘同步的是不同文件，不存在冲突。

### Q: 后台管理改了设置，平板没变化？

平板每 30 秒自动检测设置变化。想立即生效就刷新平板页面。

### Q: 重装系统/换电脑？

把整个 `shuaka/` 文件夹复制到新电脑，改一下 `config.yaml` 里的路径，重新 `pip install -r requirements.txt` 就行。Excel 数据在百度网盘里，不会丢。
