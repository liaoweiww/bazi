
# 家庭私厨 - 前端实现方案

## 一、技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 框架 | 原生 HTML + CSS + JS（SPA） | 零构建、直接运行、小程序风格 |
| 字体 | Noto Sans SC（Google Fonts） | 干净、免费、中文适配好 |
| 图标 | Unicode Emoji + 文字符号 | 无需第三方图标库 |
| 后端 | 现有 server.js（Express + MySQL） | 保留不动 |
| 通信 | fetch API 调用后端接口 | 标准方案 |

**整体架构**：单 HTML 文件 SPA，CSS 和 JS 内嵌，通过 display none/block 切换页面。所有页面数据先用内存数组模拟，后续对接后端 API。

## 二、设计系统

### 2.1 色彩

| Token | 色值 | 用途 |
|-------|------|------|
| `--c-bg` | `#FFF8F5` | 页面背景，暖白 |
| `--c-surface` | `#FFFFFF` | 卡片/表面 |
| `--c-primary` | `#F5A0B0` | 主色，粉（按钮/激活态） |
| `--c-primary-deep` | `#E8839A` | 主色深（标签文字） |
| `--c-secondary` | `#A0D8C0` | 辅色，薄荷（分类筛选激活） |
| `--c-accent` | `#C0A8E0` | 强调色，淡紫 |
| `--c-peach` | `#F5D0A0` | 暖桃色 |
| `--c-text` | `#3D2C2E` | 主文字 |
| `--c-text-secondary` | `#8A7A7C` | 次级文字 |
| `--c-text-light` | `#B8AAAC` | 弱化文字 |
| `--c-border` | `#F0E6E4` | 分割线/边框 |

### 2.2 圆角体系

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-sm` | `10px` | 小卡片、输入框 |
| `--radius-md` | `16px` | 普通卡片 |
| `--radius-lg` | `24px` | 大卡片、搜索栏 |
| `--radius-xl` | `32px` | 标签按钮、FAB |

### 2.3 阴影

| Token | 值 |
|-------|-----|
| `--c-shadow` | `0 2px 12px rgba(245,160,176,0.12)` |
| `--c-shadow-lg` | `0 4px 24px rgba(160,216,192,0.15)` |

### 2.4 布局

- 最大宽度 `480px`，居中（模拟小程序）
- 底部导航固定高度 `64px`
- 所有页面内边距左右 `20px`

## 三、页面结构树

```
App Shell
├── Page: 拿手菜 (page-recipes)
│   ├── 顶部栏 (页标题 + 菜计数 + 视图切换)
│   ├── 搜索栏
│   ├── 标签栏 (个人私有/家庭共享/待学菜谱)
│   ├── 分类过滤栏 (全部/肉类/蔬菜/海鲜/素面食/汤类/饮品/甜品/收藏/管理)
│   ├── 菜谱网格 (2列/3列/列表，三模式切换)
│   ├── FAB [+ 新增菜谱] 按钮
│   └── 模态框：新增菜谱 (从底部滑入)
│
├── Page: 点菜 (page-meals)
│   ├── 顶部栏
│   ├── 周日历 (7天水平滚动)
│   ├── 三餐时段块 (早餐/午餐/晚餐)
│   │   └── 菜品槽位 (可点击添加)
│   └── 空状态
│
├── Page: 菜场 (page-market)
│   ├── 顶部栏
│   ├── 搜索栏
│   └── 分类折叠列表 (畜禽/鲜蔬/水产/调味/五谷)
│
├── Page: 家宴 (page-feast)
│   ├── 顶部栏
│   └── 宴席卡片列表 / 空状态
│
├── Page: 我的 (page-profile)
│   ├── 用户信息卡片
│   └── 设置列表行
│
└── 底部导航栏 (5个Tab固定)
```

## 四、数据模型（前端内存）

### Recipe（菜谱）
```js
{
  id: number,
  name: string,
  category: 'meat'|'veg'|'seafood'|'noodle'|'soup'|'drink'|'dessert',
  difficulty: 'easy'|'medium'|'hard',
  cookTime: string,
  tag: 'personal'|'family'|'learning',
  emoji: string,
  notes: string,
  createdAt: Date
}
```

### MealPlan（点菜）
```js
{
  date: string,       // '2026-06-12'
  mealType: 'breakfast'|'lunch'|'dinner',
  recipeId: number|null
}
```

### Ingredient（食材库）
```js
{
  name: string,
  category: string,
  unit: string
}
```

### FeastMenu（宴席）
```js
{
  id: number,
  name: string,
  servings: number,
  eventDate: string,
  recipes: number[]
}
```

## 五、状态管理

全局 `state` 对象管理所有可变状态：

```js
const state = {
  recipes: [...],        // 所有菜谱
  currentTag: 'personal', // 当前标签
  currentCat: 'all',      // 当前分类
  searchQuery: '',        // 搜索关键词
  viewMode: 'grid-2',     // 视图模式
  selectedDay: 0,         // 选中星期几
  weekStart: Date,        // 本周起始
  mealPlans: {},          // 点菜数据
  feasts: [],             // 宴席列表
}
```

每个 Tab 切换/搜索输入/标签切换/分类点击都触发对应的 `render*` 函数重新渲染。

## 六、交互规范

| 交互 | 实现方式 |
|------|---------|
| 页面切换 | `.page` display 切换，`.nav-item` active 高亮 |
| 视图模式 | ⊞→⊟→☰ 三模式循环 |
| 搜索 | input 事件 + 300ms 防抖 |
| 标签/分类 | click 事件高亮切换 + 数据过滤 |
| 模态框 | fixed 遮罩 + 底部滑入动画 |
| 遮罩关闭 | 点击 modal-overlay 关闭 |
| Toast | fixed 底部 + opacity 过渡，2秒消失 |
| 按钮反馈 | `:active { transform: scale(0.95) }` |
| 空状态 | 各页面独立空状态文案/插画 |

## 七、实现顺序

| 阶段 | 内容 | 估算 |
|------|------|------|
| 1 | 全局 CSS 设计系统 + 底部导航 + 页面壳 | 1次 |

| 4 | 菜场：分类折叠 + 搜索过滤 | 1次 |
| 5 | 家宴：卡片列表 + 新建宴席 | 1次 |
| 6 | 我的：用户卡片 + 设置列表 | 1次 |
| 7 | 对接后端 API（后续迭代） | - |
