## 二、最简部署方案（推荐新手）

**不买RDS，不买OSS，全跑在ECS上。**

```
ECS 一台服务器
 ├── Nginx（反向代理 + HTTPS）
 ├── Node.js（后端 API）
 ├── MySQL（数据库）
 └── 图片存在服务器本地目录
```

**费用：** 每月只需 ECS 的 99元/年 ≈ 8元/月

## 三、ECS 上安装步骤（一步步来）

### 第一步：连接服务器

```bash
# 在你自己的电脑终端执行
ssh root@你的服务器IP
# 输入密码登录
```

### 第二步：安装 MySQL

```bash
# 更新系统
apt update && apt upgrade -y

# 安装 MySQL
apt install mysql-server -y

# 启动 MySQL
systemctl start mysql
systemctl enable mysql

# 设置密码（按提示输入密码）
mysql_secure_installation
```

### 第三步：安装 Node.js

```bash
# 安装 Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install nodejs -y

# 验证
node -v   # 应该显示 v18.x
npm -v    # 应该显示 9.x
```

### 第四步：安装 Nginx

```bash
apt install nginx -y
systemctl start nginx
systemctl enable nginx
```

### 第五步：上传你的后端代码

```bash
# 在你自己的电脑上操作
# 把后端代码打包上传到服务器
scp -r ./你的后端文件夹 root@你的IP:/root/app/

# 安装依赖
ssh root@你的IP "cd /root/app && npm install"
```

### 第六步：配置数据库

```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE jiashi_app DEFAULT CHARACTER SET utf8mb4;

# 创建专用用户
CREATE USER 'jiashi'@'localhost' IDENTIFIED BY '你的密码';
GRANT ALL ON jiashi_app.* TO 'jiashi'@'localhost';
FLUSH PRIVILEGES;
EXIT;

# 导入表结构（以后我给你写建表SQL）
mysql -u jiashi -p jiashi_app < /root/app/init.sql
```

### 第七步：配置 Nginx

```bash
# 编辑配置
nano /etc/nginx/sites-available/jiashi

# 填入下面内容（替换你的域名）
```

```nginx
server {
    listen 80;
    server_name 你的域名.com;
    
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
# 启用站点
ln -s /etc/nginx/sites-available/jiashi /etc/nginx/sites-enabled/
nginx -t          # 检查配置
systemctl reload nginx
```

### 第八步：配置 HTTPS（免费）

```bash
# 安装 SSL 证书
apt install certbot python3-certbot-nginx -y
certbot --nginx -d 你的域名.com
# 按提示输入邮箱，同意协议，证书自动配置
```

### 第九步：启动后端

```bash
# 用 PM2 管理进程（保证重启后自动运行）
npm install -g pm2
cd /root/app
pm2 start app.js --name jiashi
pm2 save
pm2 startup    # 按提示执行那行命令
```

2. 添加 `https://你的域名.com`
3. 提交审核发布

## 五、日常维护

```bash
# 查看运行状态
pm2 status

# 查看日志
pm2 logs jiashi

# 更新代码
cd /root/app && git pull && pm2 restart jiashi

# 备份数据库
mysqldump -u jiashi -p jiashi_app > backup_$(date +%Y%m%d).sql
```

## 六、什么时候需要升级

| 用户量 | 需要做的事 |
|--------|-----------|
| < 1000 人 | 当前 ECS 完全够用 |
| 1000-10000 人 | 升级 ECS 配置，数据库考虑迁 RDS |
| > 10000 人 | 加 OSS 存图片，加 Redis 缓存，前后端分离 |
